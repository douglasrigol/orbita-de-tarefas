# orbita-de-tarefas
Uma lista de tarefas em que cada item gira em torno de um núcleo: quanto mais perto o prazo, mais perto do centro, e a cor mostra a prioridade. O objeto 3D de cada tarefa vem do texto digitada, e concluir tarefas faz o núcleo crescer. Tem filtros por status e categoria, e os dados ficam salvos no navegador.
